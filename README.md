# Jinteia Loot Tracker

Loot-Tracker für Nihor2 / Jinteia: Alltime-Übersicht, Live-Tracking in Echtzeit, Overlay über dem Spiel, Content-Erkennung (Dungeons, Portale, Super-Elite, Turm der Unendlichkeit, Inseln von Etelascil, Kopfgelder), Drop-Alarme, Farm-Ziele und Echidna-Helfer.

## Download

👉 **[Neueste Version herunterladen](https://github.com/Elspecko/Jinteia-Loot-Tracker/releases/latest)** – dort `JinteiaLootTracker-Setup.exe` laden und starten.

- Speicherort frei wählbar, Desktop-Verknüpfung optional
- Kein .NET nötig, läuft auf Windows 10/11 (64 Bit)
- Updates: Der Tracker meldet sich beim Start, wenn es eine neue Version gibt – du entscheidest selbst, ob du aktualisierst
- Deinstallation über Windows „Apps“ – auf Wunsch werden auch alle Einstellungen und Daten komplett entfernt

Windows SmartScreen kann beim ersten Start warnen (das Setup ist nicht signiert): **Weitere Informationen → Trotzdem ausführen**.

Der Tracker liest nur die Loot-Logs des Spiels (`info_chat_loot.log`) und verändert nichts am Spiel.
